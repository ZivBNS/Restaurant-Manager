# Bistro - Restaurant Management System

**Bistro** is a comprehensive software solution designed for automated restaurant management. The system optimizes operational efficiency by managing reservations, waiting lists, and subscriber data, while providing real-time data analysis for management.

## 🛠 Technology Stack & Architecture
The project is built on a **Full-Stack** architecture, utilizing a distributed **Client-Server** model:
* **Language:** Java, developed within the Eclipse environment.
* **Database:** Relational DBMS using **MySQL** for persistent data storage.
* **Networking:** Distributed communication over **TCP/IP** (Local Area Network).
* **UI Framework:** Graphical User Interface (GUI) developed using **JavaFX**.
* **Connectivity:** **JDBC** used for seamless database integration.
* **Methodology:** Development followed **Agile/SCRUM** principles, including sprint planning and backlog management.
* **Design Pattern:** Implementation of the **ECB (Entity-Control-Boundary)** pattern and other industry-standard software design patterns.

## 🚀 Development Milestones

The development process was divided into three primary milestones, evolving from initial analysis to a fully functional system:

### Milestone 1: Requirements Analysis & Project Planning
* **Use Case Modeling:** Analyzed system operation and environment interfaces using **Visual Paradigm**.
* **Project Planning:** Established a detailed Work Breakdown Structure (**WBS**) and Gantt chart for project organization.
* **Acceptance Testing:** Defined functional requirements and prepared testing plans for core processes like table ordering and time-reporting.
* **Collaboration:** Initialized a public **GitHub** repository for version control and team coordination.

### Milestone 2: System Design & Functional Prototyping
* **UML Modeling:** Created advanced diagrams, including **Activity** (with swim-lanes), **Class**, and **Sequence** diagrams to define system logic.
* **Functional Prototype:** Developed a working "Proof of Concept" with separate Client and Server executable files to demonstrate database connectivity and CRUD operations.
* **Architecture Design:** Defined the software architecture through **Package Diagrams**.

### Milestone 3: Full Implementation & Final Delivery
* **System Realization:** Completed full implementation of core capabilities, including remote connections and distributed station support.
* **Automated Reporting:** Developed features for generating monthly visual (graphical) reports on customer arrival times and subscriber statistics.
* **Documentation:** Produced comprehensive technical documentation using **Javadoc** to detail the software structure and classes.
* **Deployment:** Finalized the project into independent **JAR** files for deployment and testing in a multi-computer environment.

## 📋 Key Features
* **Smart Reservations:** Remote booking system with real-time availability checks and unique confirmation codes.
* **Dynamic Waiting List:** Automated queuing system that notifies customers via email/SMS when tables are ready.
* **Subscriber Management:** Digital loyalty program identifying members via QR/Barcodes with visit history tracking and automatic 10% discounts.
* **Manager Dashboard:** Specialized interface for updating table layouts, adjusting opening hours, and viewing operational reports.
* **Automated Billing:** Systematic calculation of bills including specialized messaging for table clearance and payment processing.

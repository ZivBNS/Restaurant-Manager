# Bistro - Restaurant Management System

[cite_start]**Bistro** is a comprehensive restaurant management software designed to streamline table reservations, waiting lists, and subscriber management[cite: 85, 88]. [cite_start]Developed as a full-stack, distributed system, it provides a robust solution for restaurant staff and managers to optimize daily operations and enhance customer service[cite: 171, 173].

## 🛠 Technology Stack & Architecture
The system is built on a **Full-Stack** architecture with a focus on distributed computing and modular design:
* [cite_start]**Language:** Java, developed within the Eclipse environment[cite: 169, 341].
* [cite_start]**Architecture:** Distributed Client-Server model utilizing TCP/IP for local network (LAN) communication[cite: 171, 176].
* [cite_start]**Database:** Relational DBMS using **MySQL** for persistent data storage[cite: 172, 342, 364].
* [cite_start]**UI/Interface:** Graphical User Interface (GUI) developed to facilitate user interaction and communication parameter configuration[cite: 252, 343].
* [cite_start]**Connectivity:** Integration with external systems and databases via **JDBC**[cite: 223].
* [cite_start]**Methodology:** Managed using **SCRUM** principles, including sprint planning and backlog management[cite: 53, 272].
* [cite_start]**Design Pattern:** Implemented the **ECB (Entity-Control-Boundary)** pattern to structure the software logic[cite: 219].

## 🚀 Development Milestones

The project was executed in three distinct phases, moving from theoretical requirements to a fully functional production-ready system:

### Phase 1: Requirements Analysis & Project Planning
* [cite_start]**Use Case Modeling:** Conducted a thorough analysis of system operations and external interfaces using Visual Paradigm[cite: 6, 8].
* [cite_start]**Project Planning:** Defined the Work Breakdown Structure (WBS) and established a Gantt chart for the initial four weeks[cite: 16, 17].
* [cite_start]**Acceptance Testing:** Drafted detailed acceptance test plans for core features such as table reservations and time-tracking reports[cite: 28, 29, 30].
* [cite_start]**Environment Setup:** Established a public GitHub repository for team collaboration and version control[cite: 32, 33].

### Phase 2: System Design & Functional Prototyping
* [cite_start]**UML Modeling:** Created detailed Activity diagrams (with swim-lanes), Class diagrams, and Sequence diagrams to map system logic[cite: 216, 219, 225].
* [cite_start]**Design Patterns:** Integrated specific software Design Patterns to ensure code flexibility and reusability[cite: 224].
* [cite_start]**Functional Prototype:** Built a working prototype consisting of separate Client and Server JAR files capable of performing CRUD operations on the MySQL "Order" table[cite: 234, 239, 295].

### Phase 3: Full Implementation & Quality Assurance
* [cite_start]**Full Realization:** Completed the full implementation of all functional requirements, including the reservation engine and subscriber identification[cite: 337, 340].
* [cite_start]**Automated Reporting:** Developed mechanisms for monthly visual (graphical) reports on customer arrival times and subscriber activity[cite: 156, 397].
* [cite_start]**Documentation:** Produced extensive technical documentation using **Javadoc** to describe the software structure and internal class relationships[cite: 346, 366].
* [cite_start]**Final Deployment:** Prepared standalone executable JAR files for both the Client and Server components[cite: 341, 363].

## 📋 Key Features
* [cite_start]**Smart Reservations:** Remote booking system for dates up to one month in advance, providing unique confirmation codes[cite: 102, 105, 108].
* [cite_start]**Dynamic Waiting List:** Automated queuing system that notifies customers via SMS and Email when a table becomes available[cite: 119, 123].
* [cite_start]**Subscriber Management:** Digital loyalty program allowing members to track visit history and receive a 10% discount on bills[cite: 98, 137, 150].
* [cite_start]**Management Dashboard:** Interface for staff to update table layouts, modify opening hours, and manage real-time diner lists[cite: 147, 148, 153].
* [cite_start]**Automated Billing:** Systematic calculation of bills after a two-hour stay, with options for early payment and immediate table clearance[cite: 134, 136, 137].
